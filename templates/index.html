초기 아이디어를 ‘수행사가 이해할 수 있는 요구사항’으로 정리

해결할 문제

발주 초기 요구사항은 메모 수준인 경우가 많음.

예: 관리자 화면 필요, 기존 시스템 연동, 통계 필요 등

이 상태로는 수행사가 범위·설계·견적을 판단하기 어려움.

AI가 바로 RFP를 작성하는 대신 모호한 표현과 누락 가능 항목을 먼저 확인하고 요구사항을 구체화.

사용자 검토 후 요구사항 명세 → RFP 초안으로 연결.

처리 흐름

1 요구사항 입력

아이디어·메모 수준의 초기 요구사항

2 AI 분석·구체화

모호한 표현·누락 가능 항목 확인

3 사용자 검토

확인 필요사항 검토·수정

4 요구사항 명세

검토 결과를 구조화

5 RFP 초안

확정 요구사항을 RFP로 구성

핵심 기능

요구사항 분석

모호한 표현 탐지·구체화

추가 정보 확인

범위·설계·견적 판단에 필요한 정보 제안

요구사항 정리

유사 요구사항 통합·분류
불명확한 내용은 확인 필요로 분리

RFP 생성

검토가 끝난 요구사항을 기준으로 초안 생성

해커톤 MVP

범위

가상의 프로젝트와 10~20개 수준의 초기 요구사항으로 개발.

구현

자유 입력 → AI 분석 → 요구사항 표 → 사용자 수정 → RFP 초안 출력까지 구현.

제외

로그인, 프로젝트 관리, 협업·결재 기능.

장점

업무 연관성이 높고 구현 난도가 비교적 낮음

모호한 메모가 명세로 바뀌는 과정이 명확해 데모 효과가 큼

주의점

단순한 "GPT에게 RFP 써줘" 형태로 보이지 않도록 요구사항 분석·검토 단계가 핵심

기존 시스템 연동 확인 필요

연동 대상과 방식, 데이터 범위가 정의되지 않음.

AI 제안

연동 대상 시스템, API·DB 등 연동 방식, 송수신 데이터 항목 확인.

통계 기능 필요 구체화 필요

필요한 통계 항목과 조회 조건이 불명확함.

AI 제안

주요 통계 항목, 조회 기간, 엑셀 다운로드 필요 여부 확인.

사용자 권한 관리 구체화 필요

사용자별 권한 구분 기준이 정의되지 않음.

AI 제안

관리자·일반 사용자 등 역할을 정의하고 역할별 조회·등록·수정 권한 구분.

공지사항 등록 기능 구체화 가능

기본 기능은 명확하며 세부 기능 범위를 바로 구체화할 수 있음.

3

요구사항 명세

분석 결과를 수행사가 이해할 수 있는 요구사항으로 구조화

ID 분류 요구사항 상세 내용
REQ-001 관리자 관리자 기능 관리 관리자는 사용자 현황 및 주요 운영 정보를 조회·관리할 수 있어야 함.
REQ-002 연동 기존 시스템 데이터 연동 기존 시스템과 필요한 데이터를 송수신할 수 있는 연동 기능을 제공해야 함.
REQ-003 통계 통계 조회 및 다운로드 기간별 주요 통계를 조회하고 엑셀 파일로 다운로드할 수 있어야 함.
REQ-004 권한 역할별 접근 권한 관리 사용자 역할에 따라 메뉴 및 기능 접근 권한을 구분할 수 있어야 함.
REQ-005 공지 공지사항 관리 관리자는 공지사항을 등록·조회·수정·삭제할 수 있어야 함.
4

RFP 초안

확정된 요구사항을 기준으로 문서 형태로 정리

1. 사업 개요

본 사업은 기존 업무 시스템의 운영 효율화를 위해 관리자 기능, 시스템 연동, 통계, 권한 관리 및 공지사항 관리 기능을 구축하는 것을 목적으로 한다.

2. 구축 범위

  • 관리자 운영 화면 구축
  • 기존 시스템 데이터 연동
  • 통계 조회 및 엑셀 다운로드
  • 사용자 역할별 권한 관리
  • 공지사항 관리 기능 구축

3. 주요 기능 요구사항

수행사는 요구사항 명세를 기준으로 각 기능을 구현하고, 세부 설계 단계에서 발주자와 기능 범위 및 연동 방식을 협의해야 한다.

4. 확인 필요사항

  • 기존 시스템 연동 대상 및 연동 방식
  • 관리자 역할별 상세 권한 범위
  • 통계 항목 및 조회 기준
내부망 활용형

사람용 문서를 AI/RAG가 활용하기 쉬운 Markdown으로 변환

해결할 문제

PDF·DOCX·PPTX는 사람이 읽기에는 편하지만 AI 입력 과정에서 구조가 쉽게 깨짐.

  • 불필요한 줄바꿈
  • 제목·본문 계층 손실
  • 표 구조 훼손
  • 이미지 위치 분리

원문을 요약하거나 재작성하지 않고 내용과 구조를 최대한 보존한 Markdown으로 변환.

처리 흐름

1 문서 업로드

변환할 원본 문서 입력

2 Python 추출·전처리

텍스트·표·이미지 추출 및 기본 정리

3 AI 구조 판단·복원

제목·본문·문단·표 구조 분석

4 확인 필요 표시

자동 판단이 어려운 부분 분리

5 Markdown 출력

AI/RAG 활용용 문서 생성

핵심 기능
